# UMBRA

A dark silhouette weapon fighter for the browser: 1v1 only, local versus, online rooms with rollback netcode, practice bots and a training room. No story mode.

See [HANDOFF.md](HANDOFF.md) to run it, [PROGRESS.md](PROGRESS.md) for status, [VALIDATION.md](VALIDATION.md) for what was tested, and [docs/SPEC.md](docs/SPEC.md) for the full specification.

Quick start: `npm install`, then `npm run server` and `npm run dev`.

Controls (P1): WASD move, **J** attack, **K** kick, **L** ranged, **U** magic, **I** signature, **J+K** throw. P2 uses the arrows and Num1–5 (or `. / ' ; ]`). Gamepads and touch work too.
